# Aussie 8: notes for Claude

## Publishing (owner's standing instruction)

- **Always push.** After every update, commit and push straight to `main` without asking first. GitHub Pages serves `main` at https://tinymana.github.io/aussie8/, so a push is how changes go live. Tell the owner once it is up (a hard refresh may be needed).
- The repo is `tinymana/aussie8` (formerly `ianroland/aussie8`; the old URL redirects). From Claude sessions, push to `https://github.com/ianroland/aussie8` (the redirecting URL); the session's git proxy may only be authorized for that name.
- Add an entry to `devnotes.json` (newest first) for player-visible changes; the site and the in-game "What's new" read it.

## Working on the game

- The game is one file: `play/index.html`. Runtime art in `play/art/` and `play/art/manifest.js` is generated by `tools/curate_art.py`; don't edit it by hand (see README, "Art").
- Test before pushing: a full race, phone layouts (portrait and landscape), and the no-art fallback should run with no errors.
- The game does not name or depict real people, and avoids look-alikes of protected characters (see `docs/ART_INTEGRATION_REPORT.md`, "Decisions for the owner").

## Desktop / Steam build

- `desktop/` is an Electron wrapper around `play/` (copied in by `npm run prepare-game`). Game-side hooks are behind `window.A8Desktop` (`DESK` in the game) and must stay no-ops on the web.
- Don't commit `desktop/node_modules`, `desktop/dist` or `desktop/game` (gitignored). Steam setup notes: `docs/STEAM.md`.
